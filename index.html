1. Enter a sentence

DistilGPT-2 splits text into tokens, which can be words, word pieces, punctuation, or spaces. The first run downloads the model (about 85 MB) and runs it in your browser.

2. Score each input token

DistilGPT-2 predicts each token from the ones before it. A start marker supplies the context for the first token. Softmax turns the model’s raw scores (logits) into probabilities.

pᵢ = softmax(logits from the preceding context)[tokenᵢ]
Token perplexity qᵢ = 1 / pᵢ
Sentence perplexity = (q₁ × q₂ × … × qₙ)1/n

The sentence score is the geometric mean of the token scores, where n is the number of input tokens. Lower perplexity means the model found the text easier to predict.

3. Predict the next token

The last position gives probabilities for every possible next token. Before a continuation is known, exp(H) measures the model’s uncertainty across those possibilities.

H = −Σ pⱼ ln(pⱼ) across the vocabulary
Next-token distribution perplexity = exp(H)
